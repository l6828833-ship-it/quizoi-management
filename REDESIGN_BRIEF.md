# Quizio Playful Premium Redesign

## Visual Direction

Quizio will adopt a warm, collectible game aesthetic rather than a conventional utility-quiz layout. The reference’s strongest qualities are its creamy paper-like backdrop, generous rounded cards, oversized friendly type, clear reward signals, and character-led game selection. Quizio will translate those qualities into an original identity rather than reproduce the supplied artwork, layouts, or mascots.

The core palette uses **Vanilla #FFFDF4** for the canvas, **Ink #171411** for dominant text and controls, **Mango #FFB638** for coins and celebration, **Bubblegum #F45A9D** for competitive emphasis, **Aqua #14B8A6** for positive progress, **Lilac #A78BFA** for playful secondary surfaces, and **Tangerine #F59E0B** for category moments. Thin warm-gray borders, offset color shadows, hand-drawn spark accents, and 24–32-point radii create depth without visual noise.

## Original Character System

Quizio’s original mascot is **Qubi**, a curious rounded question-mark creature with an expressive face, small sneakers, and a rotating set of playful game props. Qubi appears on the home hero, empty states, selected category cards, and completion celebrations. The mascot never contains required UI text; questions, actions, and answers remain real accessible application controls.

## Screen Treatment

| Screen | Modern game treatment |
|---|---|
| Home | A welcoming header, XP-and-coin chips, a large interactive “Play a round” card led by Qubi, and bouncy category tiles. |
| Mode picker | A swipeable-feeling stack of colorful game modes with unique reward badges and short, friendly descriptions. |
| Category picker | Collection-style card grid with a distinct color, simple icon, and clear question count for each category. |
| Quiz | A calm cream game board with a rounded prompt panel, simple progress dots, an animated-feeling timer pill, and answer cards with large letter badges. |
| Results | A full reward moment using Qubi, coins/XP, score details, and one obvious replay action. |
| Progress | A friendly achievement board with colorful metric tiles, progress bars, and collectible-style level treatment. |
| Settings | A minimal preference sheet that keeps utility controls calm and visually consistent. |

## Interaction Rules

The design retains accessible contrast, 52-point minimum targets, textual status in addition to color, and distinct pressed states. Playful visual layers are decorative and never obscure a prompt, countdown, answer, explanation, or primary action. The interface remains portrait-first and optimized for a one-handed reach zone.
